# Farmacias 3D Lima

Visualización 3D interactiva de las dos sedes operativas:

- **CIDON — Lince**
- **CIATOB — Surco**

La escena usa Three.js y funciona como sitio estático, sin backend.

## Controles

- Arrastrar: rotar cámara
- Rueda: zoom
- Clic derecho + arrastrar: mover cámara

## Publicación

El repositorio incluye un workflow de GitHub Pages en `.github/workflows/pages.yml`.
